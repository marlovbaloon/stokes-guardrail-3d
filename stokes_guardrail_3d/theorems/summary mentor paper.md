# รายงานสรุป: ระบบการจำแนกกลุ่มโรคสมองเสื่อมด้วยสัญญาณ EEG

---

## 1. คำถามวิจัยที่งานวิจัยชิ้นนี้พยายามหาคำตอบคืออะไร และทำไมมันถึงคุ้มค่าหรือสำคัญต่อการศึกษาค้นคว้า?

> **คำถามหลัก:** *“เราสามารถสร้าง Framework ประมวลผลสัญญาณ EEG ที่เรียบง่าย แม่นยำ และระบุตำแหน่งความผิดปกติของสมองผู้ป่วย Alzheimer’s Disease (AD) ออกมาในเชิงพื้นที่และความถี่ เพื่อใช้เป็น Biomarker ทางการแพทย์ได้หรือไม่?”*

### ปัญหาสำคัญ:

การวินิจฉัยโรคอัลไซเมอร์ในระยะเริ่มแรกทำได้ยากในทางคลินิก ประกอบกับมีการพัฒนากลุ่มยาใหม่เพื่อชะลอการลุกลามของโรค การประเมินประสิทธิภาพยาจึงจำเป็นต้องอาศัย biomarker ของการทำงานสมองที่มีความแม่นยำและเสถียรสูงอย่างเร่งด่วน

### ตัวแปรในการศึกษา:

* **ตัวแปรต้น:**
* วิธีสกัดคุณลักษณะ (Feature extraction): เปรียบเทียบระหว่าง Fast Fourier Transform (FFT) กับ Wavelet Transform (CWT)
* อัลกอริทึม Machine Learning: เปรียบเทียบ KNN กับอัลกอริทึมอื่น ๆ
* สภาวะผู้ป่วย: ภาวะหลับตา (Eyes Closed) เทียบกับลืมตา (Eyes Open)
* ตำแหน่งสัญญาณบนหนังศีรษะ และช่วงความถี่ (Delta, Theta, Alpha, Beta, Gamma)


* **ตัวแปรตาม:**
* ความถูกต้องในการจำแนกประเภท (Classification Accuracy)
* ประสิทธิภาพตัวชี้วัด (Sensitivity และ Specificity)
* ระดับการระบุตำแหน่งความผิดปกติของโรค (Localization of QEEG feature)


* **ตัวแปรควบคุม:**
* ขนาดกลุ่มตัวอย่าง: 40 คน
* ความยาว Epoch: ตัดแบ่งช่วงสั้น ๆ เท่ากัน 4 วินาที
* กลุ่มเป้าหมาย: ผู้ป่วยอัลไซเมอร์ (AD) และกลุ่มควบคุมสุขภาพดี (HC)
* การเตรียมข้อมูล: ขั้นตอน Data Augmentation และการกรองสัญญาณรบกวนมาตรฐานเดียวกัน



### คำถามทบทวน:

1. ทำไมความยาว Epoch ต้องกำหนดไว้ที่ 4 วินาที แม้จะทดสอบหลายแบบจนได้จุดสมดุลนี้?
2. ทำไมจึงใช้กลุ่มตัวอย่างเพียง 40 คน เป็นเพราะข้อจำกัดด้านการเข้าถึงข้อมูลหรือไม่?
3. เนื่องจากสมองมนุษย์มีความต่อเนื่องและเป็นพลวัตร (Dynamic) การตรวจวินิจฉัยจึงมีความซับซ้อนเสมอใช่หรือไม่?
4. อัลกอริทึม KNN มีประสิทธิภาพใช้งานได้ดีในกรณีส่วนใหญ่จริงหรือ?

## 2. นักวิจัยก่อนหน้านี้ได้ค้นพบหรือสรุปประเด็นใดไว้บ้าง และงานวิจัยชิ้นนี้มีสิ่งใดที่แปลกใหม่?

> * **งานวิจัยก่อนหน้า:** พบตรงกันว่าผู้ป่วยอัลไซเมอร์มีภาวะ **EEG Slowing** (คลื่นความถี่ต่ำ Delta และ Theta มีกำลังสูงขึ้น ในขณะที่คลื่นความถี่สูง Alpha และ Beta ลดลง) มักพบความผิดปกติเด่นชัดบริเวณสมองส่วนหลังและด้านข้าง
> * **ข้อจำกัดเดิม:** มีการใช้ Machine Learning หลากหลายโมเดล (เช่น SVM, Random Forest, GMM) ร่วมกับฟีเจอร์เชิงเส้นและไม่เชิงเส้น แต่ยังไม่มี Framework ใดถูกนำมาใช้จริงในทางคลินิกเป็นมาตรฐาน เนื่องจากซับซ้อนสูง ขาดความยืดหยุ่น และมีปัญหา Sensitivity หรือ Specificity ต่ำเกินไป
> * **จุดเด่นของงานนี้:**
> * สร้าง Framework สำเร็จรูปใน MATLAB แบ่งเป็น 4 ขั้นตอนชัดเจน (Preprocessing -> Feature Extraction -> ML Classification -> Evaluation & Visualization) ช่วยให้ต่อยอดหรือเปลี่ยนอัลกอริทึมได้ง่ายโดยไม่ต้องเขียนโค้ดใหม่
> * พิสูจน์ว่าข้อมูล **"ภาวะลืมตา (Eyes Open)"** ให้ความแม่นยำสูงเช่นกัน (โดยเฉพาะกลุ่มอายุเกิน 70 ปี พุ่งสูงถึง 95%) ช่วยให้การเก็บข้อมูลทางคลินิกยืดหยุ่นขึ้น
> * ไม่ต้องใช้ Deep Learning ซับซ้อน เพียงใช้ FFT/CWT ร่วมกับ KNN และแบ่ง Epoch สั้น 4 วินาที ก็รีดความแม่นยำได้ถึง 99% พร้อมทำ Topographic Scalp Mapping ชี้เป้าตำแหน่งความผิดปกติได้ชัดเจน

## 3. กระบวนการหลักด้านระเบียบวิธีวิจัยคืออะไร และเหตุใดจึงเลือกแนวทางดังกล่าว?

### ขั้นตอนการดำเนินงาน:

* **การคัดเลือกกลุ่มตัวอย่าง (Case Selection):**
* ผู้ป่วย AD และกลุ่มควบคุมสุขภาพดี (HC) รวม 40 คน อิงตามเกณฑ์ NINCDS-ADRDA ผ่านการคัดกรองด้วยการทดสอบทางประสาทจิตวิทยาและการสแกนสมอง


* **การเก็บรวบรวมข้อมูลสัญญาณ (EEG Acquisition):**
* ใช้สัญญาณแบบไร้งาน (Task-free resting state) นาน 30 นาที เพื่อลดภาระความร่วมมือของผู้ป่วยที่มีความบกพร่องทางสติปัญญา
* บันทึกแยกตามสภาวะลืมตา (EO) และหลับตา (EC) ผ่านระบบอิเล็กโทรด 10/10 ดัดแปลง อัตราการสุ่มตัวอย่าง 2 kHz


* **การเตรียมข้อมูลและจัดการสิ่งรบกวน (Pre-processing & Artefact Removal):**
* ตรวจสอบสัญญาณร่วมกับวิดีโอ คัดเลือกช่วงสัญญาณปราศจากสิ่งรบกวนความยาว 12 วินาทีแรก
* ใช้ High-pass filter ที่ 2 Hz ลดทอนสัญญาณรบกวนความถี่ต่ำ (เช่น การกะพริบตาและการเคลื่อนไหว)


* **การเพิ่มปริมาณข้อมูล (Data Augmentation):**
* แบ่งซอยสัญญาณจากความยาว 12 วินาที เป็นช่วงสั้น ๆ ช่วงละ 4 วินาที เพื่อเพิ่มจำนวนตัวอย่างสำหรับฝึกสอน Machine Learning โดยคงป้ายกำกับ (Label) เดิมไว้



### โครงสร้าง Framework (4 ขั้นตอน):

1. Data Augmentation
2. Feature Extraction
3. Classification
4. Evaluation & Visualization

### เหตุผลที่เลือกแนวทางดังกล่าว:

* **เลือกใช้ Task-free EEG:** เหมาะกับผู้ป่วยอัลไซเมอร์ที่มีปัญหาความบกพร่องทางสติปัญญา ไม่สามารถปฏิบัติงานซับซ้อนในห้องปฏิบัติการได้ การพักผ่อนเฉย ๆ จึงปฏิบัติจริงได้ง่ายที่สุดในทางคลินิก
* **เลือกวิธี Data Augmentation:** แก้ไขข้อจำกัดข้อมูลทางการแพทย์ที่มีจำนวนน้อย (ต่ำกว่า 50 คน) การแบ่งซอยสัญญาณช่วงสั้น ๆ ช่วยเพิ่มตัวอย่างให้พอเหมาะกับการเทรน Machine Learning โดยไม่เสียคุณลักษณะทางไฟฟ้าของสมอง

## 4. มีหลักฐานอะไรบ้างที่สนับสนุนข้อสรุปหลัก และมีข้อจำกัดอย่างไรบ้าง

### A. หลักฐานเชิงประจักษ์ที่สนับสนุนข้อสรุป

* ผลลัพธ์ยืนยันว่าการใช้ Wavelet Transform (CWT) ร่วมกับ Machine Learning (KNN) บนช่วงสัญญาณสั้นเพียง 4 วินาที สามารถรีดความแม่นยำในการจำแนกโรคได้สูงถึง 99% **(แต่มีข้อสังเกตที่ต้องตั้งคำถามว่า: เราควรละเลยความผิดพลาด 1% นี้หรือไม่?)**
* ผลวิเคราะห์ Topography ชี้ชัดว่าช่องสัญญาณบริเวณสมองส่วนขมับ (Temporal), ข้างศีรษะ (Parietal), และท้ายทอย (Occipital) มีความผิดปกติสม่ำเสมอ สอดคล้องกับพยาธิวิทยาของอัลไซเมอร์
* สถิติยืนยันว่าคลื่นความถี่ Delta และ Theta มีกำลังสูงขึ้น (EEG Slowing) สอดคล้องกับระดับความบกพร่องทางสติปัญญาของผู้ป่วย

### B. ข้อจำกัดและอคติของงานวิจัย

* **ขนาดกลุ่มตัวอย่างเล็กเกินไป:** อาสาสมัคร 40 คนมาจากภูมิลำเนาและโรงพยาบาลเดียวกัน ขาดความหลากหลายทางชีวภาพ ชาติพันธุ์ และสิ่งแวดล้อม ส่งผลให้ความสามารถในการนำไปใช้จริงในวงกว้าง (Generalizability) มีข้อจำกัดสูง
* **ความเสี่ยง Overfitting จาก Data Augmentation:** การซอยสัญญาณช่วยเพิ่มตัวอย่างเชิงสถิติแต่ไม่ได้สร้างข้อมูลเชิงชีวภาพใหม่ เสี่ยงต่อภาวะ Overfitting เมื่อเจอข้อมูลผู้ป่วยรายใหม่จากบริบทอื่น
* **จุดบอดประสิทธิภาพในกลุ่มผู้สูงอายุปลาย:** ค่า Sensitivity ในกลุ่มผู้สูงอายุเกิน 70 ปี ดิ่งลงเหลือเพียง 64%–67% ชี้ให้เห็นว่าโมเดลยังมีจุดอ่อนเมื่อต้องใช้งานกับกลุ่มเป้าหมายหลักจริง ๆ
* **การทำลายข้อมูลเชิงเวลา (Temporal Information):** แม้จะอ้างอิงว่าสมองเป็นระบบพลวัตร แต่ขั้นตอนการสกัดฟีเจอร์กลับใช้วิธีหาค่าเฉลี่ยรวบยอด (Average Magnitude) ซึ่งทำลายข้อมูลเชิงเวลาบางส่วนไป
